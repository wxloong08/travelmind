# TravelMind 城市图片资源收集表

## 📌 使用说明

1. 访问 Unsplash: https://unsplash.com
2. 搜索对应城市/景点（用英文搜索效果更好）
3. 点击喜欢的图片，复制 URL 中的图片 ID
4. 填入下表的 `photo_id` 字段
5. 完成后运行脚本生成 `image_service.py`

## 🔗 直链格式

```
海报背景（竖版）: https://images.unsplash.com/photo-{photo_id}?w=800&h=1200&fit=crop&q=80
地标图片（横版）: https://images.unsplash.com/photo-{photo_id}?w=1200&h=800&fit=crop&q=80
缩略图:         https://images.unsplash.com/photo-{photo_id}?w=400&h=300&fit=crop&q=80
```

## 🔧 生成代码

收集完图片后，运行以下 Python 脚本生成 `image_service.py`：

```python
# generate_image_service.py

# 填入你收集的图片 ID
CITY_IMAGES = {
    "北京": {
        "photo_id": "你收集的ID",
        "landmark_name": "故宫/天安门",
    },
    "上海": {
        "photo_id": "你收集的ID",
        "landmark_name": "外滩/陆家嘴",
    },
    # ... 其他城市
}

ATTRACTION_IMAGES = {
    "故宫": "你收集的ID",
    "长城": "你收集的ID",
    # ... 其他景点
}

def generate_url(photo_id, w=800, h=1200):
    return f"https://images.unsplash.com/photo-{photo_id}?w={w}&h={h}&fit=crop&q=80"

# 生成配置
for city, data in CITY_IMAGES.items():
    pid = data["photo_id"]
    print(f'"{city}": {{')
    print(f'    "landmark": "{generate_url(pid, 1200, 800)}",')
    print(f'    "poster_bg": "{generate_url(pid, 800, 1200)}",')
    print(f'    "thumbnail": "{generate_url(pid, 400, 300)}",')
    print(f'    "地标": "{data["landmark_name"]}",')
    print(f'}},')
```

## 📝 备注

- Unsplash 图片可免费商用，但建议在应用中注明来源
- 如果某个城市/景点在 Unsplash 上找不到好图，可以尝试 Pexels: https://www.pexels.com
- 主题公园（环球影城、迪士尼）由于版权问题，Unsplash 上可能没有，建议用通用的游乐场图片或留空
