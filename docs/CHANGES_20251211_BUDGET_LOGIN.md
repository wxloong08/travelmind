## 1. 预算仪表盘修复

### 问题
- 预算仪表盘显示的是 LLM 估算的**范围数据**（如 ¥800-1500）
- 但总预算却是一个具体数字（¥2,900）
- 这在逻辑上是矛盾的，用户体验差

### 解决方案
重写 `BudgetDashboardWidget`，基于实际行程数据计算精确预算：

**修改文件**: `frontend/src/components/sidebar/SmartSidebar.jsx`

```javascript
// 基于实际行程计算精确预算
const calculateBudget = () => {
    // 1. 从 itinerary 中提取酒店价格
    // 2. 根据景点名称匹配门票价格表

    // 4. 餐饮按 ¥150/天 估算
```

## 3. 登录功能

### 新增文件
| 文件 | 说明 |
|------|------|
| `frontend/src/store/useAuthStore.js` | 认证状态管理 |
| `frontend/src/components/auth/LoginModal.jsx` | 登录弹窗组件 |
| `frontend/src/components/auth/index.js` | 组件导出 |

### 修改文件
- `frontend/src/App.jsx` - 添加 UserButton 组件到头部

### 功能特性
1. **游客模式**: 设备指纹识别，每日限制使用
2. **手机号登录**: 短信验证码登录/注册
3. **Token 管理**: 自动刷新、持久化存储
4. **用户界面**: 登录弹窗、用户头像下拉菜单

### 登录流程
```
┌──────────────────────────────────────┐
│          首次访问                    │
├──────────────────────────────────────┤
│ 1. 生成设备指纹                      │
│ 2. 调用 POST /auth/guest            │
│ 3. 获取 guest_token                 │
│ 4. 可以使用基本功能                  │
└──────────────────────────────────────┘
            ↓ 点击登录
┌──────────────────────────────────────┐
│          手机号登录                  │
├──────────────────────────────────────┤
│ 1. 输入手机号                        │
│ 2. 获取验证码 (开发模式会显示)        │
│ 3. 输入验证码                        │
│ 4. 登录成功，获取 access_token       │
│ 5. 游客数据迁移到用户账号            │
└──────────────────────────────────────┘
```

## 4. API 变更

### 认证 API
| 端点 | 方法 | 说明 |
|------|------|------|
| `/auth/guest` | POST | 获取游客 Token |
| `/auth/sms/send` | POST | 发送验证码 |
| `/auth/sms/verify` | POST | 验证并登录 |
| `/auth/refresh` | POST | 刷新 Token |
| `/auth/me` | GET | 获取用户信息 |

### TokenResponse 结构变更
```json
{
    "access_token": "...",
    "refresh_token": "...",
    "token_type": "bearer",
    "expires_in": 3600,
    "user_id": "uuid",
    "user": {
        "id": "uuid",
        "phone": "138****8000",
        "nickname": null,
        "avatar_url": null
    },
    "is_new_user": false
}
```
