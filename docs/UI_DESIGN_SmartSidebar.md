## 组件尺寸规范

### 宽屏模式 (≥1440px)

| 区域 | 宽度 | 说明 |
|------|------|------|
| 聊天区域 | 320px (固定) | 对话历史 |
| 行程区域 | flex-1 (剩余空间) | 主内容区 |
| 智囊侧边栏 | 320px (固定) | 辅助信息 |

### 中等屏幕 (1024-1439px)

| 区域 | 宽度 | 说明 |
|------|------|------|
| 聊天区域 | 280px | 略窄 |
| 行程区域 | flex-1 | 主内容区 |
| 智囊侧边栏 | 收起为图标栏 48px | 点击展开浮层 |

### 移动端 (<1024px)

Tab 切换：聊天 | 行程 | 智囊

## 交互设计

### 侧边栏展开/收起

```javascript
// 中等屏幕下的侧边栏行为
const SidebarToggle = () => {
  const [isExpanded, setIsExpanded] = useState(false);
  
  return (
    <>
      {/* 收起状态：显示图标栏 */}
      <div className="sidebar-icons">
        <button onClick={() => setIsExpanded(true)}>
          <MapIcon />
        </button>
        <button>
          <WeatherIcon />
        </button>
        <button>
          <NewsIcon />
        </button>
        <button>
          <BudgetIcon />
        </button>
      </div>
      
      {/* 展开状态：浮层显示 */}
      {isExpanded && (
        <div className="sidebar-overlay">
          <SmartSidebar onClose={() => setIsExpanded(false)} />
        </div>
      )}
    </>
  );
};
```

### 天气异常提醒

```javascript
// 检测异常天气并提醒
const checkWeatherAlert = (forecasts, itinerary) => {
  return forecasts.map((forecast, index) => {
    const day = itinerary[index];
    if (!day) return null;
    
    // 检查是否有户外活动遇到恶劣天气
    const hasOutdoorActivity = day.activities.some(
      a => ['景点', '公园', '广场'].some(t => a.title.includes(t))
    );
    
    const isBadWeather = ['雨', '雪', '雷'].some(
      w => forecast.condition.includes(w)
    );
    
    if (hasOutdoorActivity && isBadWeather) {
      return {
        day: index + 1,
        message: `第${index + 1}天有${forecast.condition}，建议调整户外行程`,
        severity: 'warning'
      };
    }
    
    return null;
  }).filter(Boolean);
};
```
