## 各组件职责与必要性

### 1. Redis - 会话状态存储

| 环境 | 是否必需 | 说明 |
|------|---------|------|
| 开发/演示 | ⚪ 可选 | 使用内存存储，重启丢失 |
| **生产** | 🔴 **必需** | 会话持久化，多实例共享 |

**用途：**
```
用户: "帮我规划杭州三日游"
     ↓
[会话状态存入 Redis]
     ↓
用户: "预算3000元"  ← 需要知道上一轮说的是杭州
     ↓
[从 Redis 读取会话状态]
```

**不配置 Redis 的后果：**
- ❌ 服务重启 → 所有对话历史丢失
- ❌ 多实例部署 → 会话无法共享
- ❌ 多轮对话 → 上下文可能丢失

**配置：**
```bash
REDIS_URL=redis://localhost:6379/0
```

## 部署场景配置建议

### 场景 1：本地开发 / 面试演示

```bash
# .env
DASHSCOPE_API_KEY=sk-xxx    # 必需
AMAP_API_KEY=xxx            # 必需
# 其他都可以不配置
```

```bash
# 启动
python -m uvicorn src.main:app --reload
```

### 场景 2：生产环境（单机）

```bash
# .env
DASHSCOPE_API_KEY=sk-xxx
AMAP_API_KEY=xxx
BOCHA_API_KEY=xxx           # 建议配置

REDIS_URL=redis://localhost:6379/0       # 必需
DATABASE_URL=postgresql://...            # 建议配置

LANGFUSE_PUBLIC_KEY=pk-xxx               # 建议配置
LANGFUSE_SECRET_KEY=sk-xxx
LANGFUSE_HOST=http://langfuse:3000
```

```bash
# 启动
docker-compose up -d
```

### 场景 3：生产环境（多实例 / K8s）

```bash
# 必须配置 Redis（会话共享）
REDIS_URL=redis://redis-cluster:6379/0

# 必须配置 PostgreSQL（数据持久化）
DATABASE_URL=postgresql://user:pass@rds:5432/travelmind

# 建议外部托管 Langfuse
LANGFUSE_HOST=https://langfuse.yourdomain.com
```

## 为什么初始设计标记为"可选"

**设计权衡：**

| 考虑因素 | 选择 |
|---------|------|
| 快速启动 | 最小依赖，一条命令能跑 |
| 面试演示 | 单次对话足够展示能力 |
| 渐进增强 | 先跑通，再加持久化 |

**但这不代表生产可以不用！**

现在代码已更新，会自动检测 Redis：
- 有 Redis → 使用 Redis 持久化
- 无 Redis → 降级到内存（并打印警告）

```python
# src/graphs/travel_graph.py
def _get_checkpointer():
    if settings.redis_url:
        # 尝试 Redis
        return RedisSaver(...)
    # 回退到内存（带警告）
    logger.warning("Using in-memory checkpointer - sessions will be lost!")
    return MemorySaver()
```
